# Web Portofolio - Natanael Barzilai

Website portofolio pribadi responsif yang dibangun menggunakan HTML5, CSS3, JavaScript, dan framework Bootstrap 5. Proyek ini dibuat sebagai bagian dari tugas workshop/praktik mandiri pemrograman web.

## 🛠️ Teknologi yang Digunakan
- **HTML5:** Menyusun struktur halaman secara sementik (header, nav, section, footer).
- **CSS3:** Custom styling untuk tata letak, warna, font Google (Poppins), dan animasi transisi.
- **Bootstrap 5:** Framework CSS untuk komponen UI (Navbar, Card, Grid System, Form) dan keterbacaan di layar responsive.
- **Bootstrap Icons:** Ikon pendukung untuk kontak dan keahlian.
- **JavaScript:** Menambahkan fungsi interaktif (Dark Mode Toggle & handling form kontak).

## ✨ Fitur Utama
1. **Responsive Design:** Tampilan fleksibel dan rapi saat diakses dari HP (mobile), tablet, maupun desktop.
2. **Dark Mode Toggle:** Fitur untuk mengubah mode tampilan website dari terang (light) ke gelap (dark).
3. **Smooth Scroll:** Navigasi antarseksi halaman secara halus.
4. **Form Interaktif:** Notifikasi sederhana saat pengguna mengirimkan pesan pada section kontak.
5. **Section Lengkap:** Terdiri dari Home, About, Skills, Projects, dan Contact.
